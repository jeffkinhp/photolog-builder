# Build a static photo gallery webpage from a folder of images

A lightweight, self-hosted photo gallery with no server-side dependencies.  You put photos (e.g. jpgs) into subfolders, a Python script generates thumbnails and a JSON index, and a single HTML file renders everything in the browser.

## How it works

- `generate_photos_json.py` scans your `photos/` folder, generates 400×400 thumbnails in a `thumbs/` folder, generates a captions.txt file for entering captions, and writes `photos.json`
- `index.html` fetches `photos.json` and renders the gallery (thumbnail grid on the main page, full-size lightbox with caption on click)
- captions are managed via a `captions.txt` file in each album folder, synchronized to the photos.json by the script

No PHP, no database, no build step.  Generates files in your local copy, then FTP your local to your static web server.

## File structure

```
photo-webpage/
├── index.html
├── generate_photos_json.py
├── photos.json                  # generated — do not edit by hand
├── photos/
│   └── My Album/                # put your image files here 
│       ├── captions.txt         # generated by the script, then edit by hand to write captions
│       ├── photo1.jpg
│       └── photo2.jpg
└── thumbs/
    └── My Album/                # generated by script - 400×400 thumbnails
        ├── photo1.jpg
        └── photo2.jpg
```

## Requirements

- Python 3.8+
- [Pillow](https://python-pillow.org/) (`pip install Pillow`)
- Any web host (e.g. Apache)

## Setup

**Point `index.html` at the JSON file** (already done if you cloned this repo):

In `index.html`, confirm line ~312 reads:
```js
const PHOTOS_API = 'photos.json';
```

## Workflow

### First run

1. Add your photos into subfolders under `photos/` — each subfolder becomes an album
2. Run the script to index, create thumbs and generate captions.txt:
   ```bash
   cd photo-webpage
   python generate_photos_json.py
   ```
3. Open each album's `captions.txt` and fill in any captions (optional)
4. Run the script again to bake captions into `photos.json`
5. Upload everything to your web host

### Adding captions

Each album folder contains a `captions.txt` created when the script is first run (seeded with empty captions).  Add captions using your favorite text editor:

```
# Captions for this album.
# Format: filename TAB caption text  (leave caption blank for none)
#
photo1.jpg	Caspian tern at Millennium Park, April 22
photo2.jpg	American goldfinch, disco dancing (banana variant)
photo3.jpg
```

The separator between filename and caption must be a **tab character**. Lines starting with `#` are comments. Captions appear in the lightbox below the full-size photo; photos with no caption show only the position counter.

After updating the captions.txt file(s), re-run the script to draw the captions in to the JSON.

### Adding or removing photos

1. Add/remove images in the relevant `photos/` subfolder
2. Run `python generate_photos_json.py` — it updates `captions.txt` (adding blank lines for new photos, removing lines for deleted ones) and regenerates thumbnails for new images only
3. Fill in captions for any new photos in `captions.txt`
4. Run the script once more
5. Upload `photos.json`, any new images, their thumbnails, and `index.html`

## Script options

```bash
python generate_photos_json.py           # normal run
python generate_photos_json.py --rebuild # regenerate all thumbnails from scratch
```

## Supported image formats

`.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.avif`

## Local preview

Browsers block `fetch()` on local files, so you can't preview by opening `index.html` directly. Use Python's built-in server instead:

```bash
cd photo-webpage
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
